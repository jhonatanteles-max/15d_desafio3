🔐 Sistema de Login em PHP
👋 Sobre o projeto
Esse projeto foi desenvolvido com o objetivo de colocar em prática meus conhecimentos em PHP, HTML e CSS, criando um sistema simples de login e perfil de usuário.

A ideia foi desenvolver uma aplicação onde o usuário consegue entrar com seu e-mail e senha, visualizar suas informações pessoais, personalizar a cor de fundo da página e sair do sistema quando quiser.

Um detalhe interessante é que o projeto não utiliza banco de dados. As informações do usuário ficam armazenadas diretamente em um array no próprio código PHP, e o controle de acesso é feito utilizando sessões.

✨ O que o sistema faz?
Permite realizar login com e-mail e senha.
Mostra uma mensagem de erro caso os dados estejam incorretos.
Mantém o usuário conectado utilizando sessões PHP.
Exibe o nome e o e-mail do usuário após o login.
Cria um avatar com a primeira letra do nome.
Permite escolher e alterar a cor de fundo da página.
Possui uma opção para sair do sistema e encerrar a sessão.
🛠️ Tecnologias utilizadas
PHP – responsável pela lógica do sistema e autenticação.
HTML5 – estrutura das páginas.
CSS3 – estilização e aparência visual.

🚀 Como executar o projeto
Para rodar o projeto no seu computador, é bem simples:

Instale o XAMPP.
Inicie o Apache.
Coloque a pasta do projeto dentro da pasta htdocs.
Certifique-se de que o arquivo principal está salvo como index.php.
